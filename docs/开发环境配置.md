# LifeOS 开发环境配置

本文档用于 Windows 10/11 上的 LifeOS Android 与 Spring Boot 开发环境。版本应与仓库 CI 保持一致。

## 1. 必需版本

| 工具 | 基线版本 |
| --- | --- |
| Flutter | 3.44.8 stable |
| Dart | 3.12.2（随 Flutter 提供） |
| Android SDK | 由当前 Android Studio 稳定版管理 |
| Java | 17 LTS |
| Maven | 3.9.9（项目 Wrapper 自动提供） |
| MySQL | 8.4 LTS |

## 2. Android 环境

1. 安装 Android Studio 稳定版。
2. 通过 SDK Manager 安装 Android SDK Platform、Build-Tools、Platform-Tools 和 Emulator。
3. 将 Flutter stable SDK 放在非临时、无特殊权限的目录，并把 `flutter/bin` 加入用户 PATH。
4. 执行：

```powershell
flutter config --android-sdk <Android SDK 路径>
flutter doctor --android-licenses
flutter doctor -v
```

验收要求是 `Flutter` 与 `Android toolchain` 均显示通过。LifeOS 不开发 Windows 桌面端，因此 `Visual Studio` 缺失不影响本项目。

## 3. vivo X100s 真机

1. 在手机中开启开发者选项和 USB 调试。
2. 使用支持数据传输的 USB 线连接电脑，并在手机上确认调试授权。
3. 执行 `adb devices`，确认设备状态为 `device`，而不是 `unauthorized`。
4. 执行 `flutter devices` 和 `flutter run`。
5. 后续涉及提醒或后台任务时，单独验证 vivo 系统的通知权限、自启动与节电限制。

## 4. Java 环境

Spring Boot 3 必须使用 Java 17 或更高版本。本机如果同时安装 Java 8，需要确保 `JAVA_HOME` 指向 Java 17，并让 `%JAVA_HOME%\bin` 位于旧版 Java 路径之前。

```powershell
java -version
cd server
.\mvnw.cmd -version
```

两处均应显示 Java 17。Android 构建也可使用 Android Studio 自带的 JDK 17。

## 5. 验证命令

移动端：

```powershell
cd mobile
flutter pub get
dart run build_runner build
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

服务端：

```powershell
cd server
.\mvnw.cmd --batch-mode spotless:check verify
```

本地 Android 环境未准备好时，GitHub Actions 仍会执行 Android debug APK 构建，但真机兼容性必须在 vivo X100s 上完成，不能由 CI 代替。
