# LifeOS 架构决策记录（ADR）

本目录记录对 LifeOS 有长期影响的技术决策。ADR 一经接受不直接改写结论；如决策发生变化，应新增 ADR 并标记被替代关系，以保留演进原因。

状态说明：

- `Proposed`：提议中，尚未作为工程约束
- `Accepted`：已接受，工程实现必须遵守
- `Deprecated`：不再建议用于新代码
- `Superseded`：已被后续 ADR 替代
