# Stage 2：Diary 日记模块设计

## 1. 目标

Diary 用于记录人生，而不是要求用户写完整的流水账。每个自然日保存一篇可持续编辑的日记，一句话、一种感受或一张图片都可以成为当天的记录。

本模块交付：

- 每个本地自然日最多一篇有效日记。
- Markdown 原文编辑与安全预览。
- 每日日记模板和最多 10 个自由标签。
- 每篇最多 9 张本地图片附件。
- 日记、标签和附件元数据保存在 SQLite；图片文件保存在应用私有目录。
- 创建、编辑、按日期倒序查看和软删除日记。

## 2. 模块边界

```text
presentation -> application -> domain
data ------------------------> domain
```

- 页面只通过 `DiaryService` 和 Riverpod Provider 操作数据。
- `DiaryRepository` 是日记聚合的领域端口，Drift 是 Phase 1 的本地适配器。
- `DiaryAttachmentStore` 隔离图片解码、隐私处理和私有文件操作，后续可替换为加密或同步实现。
- Markdown 原文是事实源，预览结果不写入数据库。
- Diary 不在本阶段自动向 AI 发送正文、标签或图片。

## 3. 数据模型与迁移

SQLite schema 从 v4 升级到 v5，新增三张表：

### `diary_entries`

- `id`：客户端 UUID。
- `local_date`：日记所属的本地自然日。
- `markdown`：1 至 50000 个字符的 Markdown 原文。
- `created_at / updated_at / version / deleted_at`：通用审计和软删除字段。
- 使用部分唯一索引约束同一自然日最多一篇未删除日记；删除后允许重新创建。

### `diary_tags`

- 每个标签拥有独立 UUID、原始名称、规范化名称和显示顺序。
- 每篇最多 10 个标签，每个标签最多 20 个字符。
- 标签去除首尾空白，并按不区分大小写的规范名称去重。

### `diary_attachments`

- 保存主图和缩略图的应用内相对路径，不保存 BLOB 或相册绝对路径。
- 保存媒体类型、文件大小、宽高、SHA-256、顺序和生命周期时间。
- `deleted_at` 表示附件进入待清理状态；`files_deleted_at` 表示文件已完成物理清理。

v1、v2、v3、v4 数据库均使用增量迁移升级，不重建或清空已有数据。

## 4. 图片隐私与生命周期

图片导入遵循以下流程：

1. 系统照片选择器返回临时文件，LifeOS 不修改相册原图。
2. 校验文件存在、大小不超过 20 MB、格式可解码且像素数量处于安全范围。
3. 修正图片方向，最长边压缩至 2048px，统一重新编码为质量 88 的 JPEG，从输出中移除 EXIF 定位等元数据。
4. 生成最长边 480px 的缩略图，并计算主图 SHA-256。
5. 编辑期间写入应用私有 `diary/pending` 目录；保存时先复制到 `diary/attachments`，再事务写入数据库。
6. 数据库保存失败时删除已复制的正式文件，暂存文件保留以便重试；保存成功后移除暂存副本。
7. 放弃编辑时清除本次暂存图片；异常退出遗留的暂存文件在 24 小时后维护清理。
8. 移除附件或删除日记后先软删除元数据，文件保留 7 天，再由可重试维护任务物理清理。

所有路径在文件存储边界检查，禁止绝对路径和 `..` 路径逃逸。Android 已禁用自动备份，因此卸载应用会删除本地日记和图片；界面会明确提示这一限制。

## 5. Markdown 安全策略

- Markdown 预览不执行 HTML 或脚本。
- Markdown 中的远程图片不会加载，避免无意向第三方发送网络请求。
- 外部链接不会由预览直接打开，并向用户说明隐私原因。
- 日记正文、标签和图片信息不写入日志或错误提示。

## 6. 交互原则

- “写今天”优先打开今天的日记；今天已存在时显示“继续写”。
- 新建日记可以选择日期，编辑已有日记时日期固定，避免误覆盖另一日记录。
- 编辑与预览在同一页面切换，并可一键插入温和的每日日记模板。
- 图片选择、压缩和保存期间显示忙碌状态；单张失败不丢弃已经处理成功的图片。
- 删除前二次确认，并明确图片将在 7 天后清理。

## 7. 测试与验收

- 应用服务验证每日唯一、Markdown/标签规则、图片晋升和元数据保存。
- Drift 验证聚合事务、部分唯一索引、软删除和附件延迟清理状态。
- schema v1/v2/v3/v4 → v5 增量迁移测试。
- 私有图片存储验证 2048px 主图、480px 缩略图、SHA-256、原图不变和路径逃逸防护。
- 从空状态创建首篇 Markdown 日记的 Widget 测试。
- `dart format`、`flutter analyze`、`flutter test` 和 Android Debug APK 构建。
- vivo X100s 真机验证图片选择、Vivo 相册权限、Markdown 预览、重启持久化和卸载数据提示。
